# FiiCode 2026 Predictive Demand Challenge

This repository contains the codebase for the demand forecasting challenge at FiiCode 2026. We achieved a competitive public leaderboard score of **2.0704** by leveraging recursive gradient-boosted models and an ensemble blending strategy.

For detailed information on our top models, see:

## How to Replicate

## Repository Structure
- `exports/`: Contains prediction CSVs and experiment logs.
- `docs/`: Documentation and replication guides.
- `*.py`: Feature engineering pipelines and model training scripts.
- `*.ipynb`: Experimental notebooks.
